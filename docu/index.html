geo-lod documentation

Documentation of the geo-lod data model for ice cores (EPICA), speleothems (SISAL) and the Campanian Ignimbrite (CI). The pages are generated from the ontology files and the RDF graphs of this repository.

46geolod: classes, 30 object and 37 datatype properties
10strat: classes, 23 object and 6 datatype properties
6an: classes, 2 object and 3 datatype properties
  • Data model: Class hierarchies, relations and tables per module.
  • CRM coverage: Which classes reach the CIDOC CRM family, and how.
  • Crosswalk: Every defined or used class, drawn with its chain to the CRM family.
  • Instance models: One EPICA, SISAL and CI resource with its neighbours.
  • Query: Eight queries over a sample graph, run in the browser.
  • Slide figures: The twelve figures of the CHNT31 talk.
